AI のつなぎ方
  1. Claude Code で、次のコマンドを一度だけ実行します。
  2. Claude Code に、作りたいものを頼みます。
    bpy-modeler で木製のスツールを作って。座面は直径35cmの円形で縁を丸く、脚は4本で少し外に開く。高さ45cm
  3. AI がスクリプトを書いて実行し、検査結果と絵を見ながら直します。結果はこの画面に出ます。

Claude Desktop など、ほかのアプリからつなぐ方法は README を見てください。

    マテリアル

    • —

    textures フォルダの画像と同じ名前のマテリアルに、その画像が貼られます。UV は自動で作ります。

    書き出し

    FBX OBJ（zip） GLB STL（mm）

    GLB・OBJ はメートル、FBX はセンチ、STL はミリ（1 = 1mm、Z が上。CAD 向け）で書き出します。どれも実寸です。ファイルは output フォルダにも残ります。

    図鑑

    図鑑を開く

    スクリプトで qm.catalog(...) を使って登録した部品ごとに、等角図・三面図（寸法つき）・部品表を 1 ページずつ描きます。印刷・PDF にもできます。
