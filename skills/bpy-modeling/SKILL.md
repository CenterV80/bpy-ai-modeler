# bpy-modeler でモデルを作る

bpy-modeler は、Blender（GUI なし）でスクリプトを実行し、トポロジーと配置を検査して結果を返す MCP サーバー。
目標は「手作業で丁寧にモデリングしたような、四角ポリゴン主体のきれいなメッシュ」を、頼まれた形と寸法で作ること。

## 進め方

1. **qm_help を読む**（初回だけ）。部品は qm の関数で作るのが基本。自分で bmesh を組むのは qm で作れない形だけにする。
2. **寸法を決める**。頼まれていない寸法は、下の「寸法の目安」から実物らしい値を選ぶ。決めた主な寸法は
   スクリプトの先頭に定数で書き、`qm.expect()` で宣言する。
3. **大まかな形から**。最初の run_script は主要な塊だけ（本体・ふた・脚など）。細部（帯・金具・面取り）は後から足す。
4. **render で見る**。`render(views=["persp", "front", "side"])` で比率と配置を確かめる。数字の検査は
   「浮いている」は見つけられるが、「めり込んでいる」「向きが逆」「比率がおかしい」は絵でしか分からない。
5. **細部を足す → 検査 → render** を繰り返す。テクスチャは `render(look="material")` で確かめる。
6. 終わったら、作ったもの・寸法・面数・マテリアルをユーザーに短く伝える。保存先を頼まれたら `export`。

検査で問題が返ってきたら、形を保ったまま直す。問題を残して終える場合は、その理由をユーザーに伝える。

## 部品の作り方（どの qm を使うか）

| 作りたいもの | 使う関数 | コツ |
|---|---|---|
| 箱・板・棚板・壁 | `qm.box` | 角は `bevel=` で少し丸めると実物らしくなる（1〜2cm 程度） |
| 丸い脚・柱・棒・貫 | `qm.cylinder`（`axis="X"` / `"Y"` で横向き） | seg は 8〜16。細い物は 8 で十分 |
| 先細りの脚・曲がった取っ手・パイプ・つる | `qm.tube`（点ごとの半径も可） | 点は 4〜8 個。曲がり角は点を増やす |
| 壺・瓶・皿・ボタン・座面（丸） | `qm.lathe` | 断面は下から上へ。端は半径>0 で終えてフタ（四角形）にする。極（半径0）は三角形になる |
| かまぼこ型・アーチ・断面が変わる物 | `qm.loft` | 断面の点数をそろえる。端は自動で四角形の格子になる |
| 帯・縁・額縁・レール（断面を道すじに沿って） | `qm.sweep` | 箱に巻くなら道すじを箱の面から厚みの半分だけ外に。輪は `closed_path=True` |
| 球・卵・クッション・金貨の山 | `qm.quad_sphere` | 大きさを (X, Y, Z) で変えれば楕円体。四角形だけ |
| 自分で組んだ面の穴 | `qm.cap_grid` | 輪の頂点数を偶数にする |
| 開いたふた・扉・傾けた部品 | `qm.pivot` | 軸の点は「回る辺の上の点」。ふたなら奥の上の辺 |
| 左右対称の部品 | `qm.copy` | location / rotate を変えて複製する |
| なめらかな曲面（クッション・車体） | `qm.box(segs=...)` ＋ `qm.subsurf` | 角を残したい所の近くに分割（サポートエッジ）を入れる |
| ボルト・ナット・座金 | `qm.bolt` / `qm.nut` / `qm.washer` | サイズは "M3"〜"M12"。ボルトの原点は頭の座面。見せたいときだけ `thread=True`（面が多い） |
| 歯車 | `qm.gear` | かみ合わせるなら同じ module にし、中心距離 = module ×（歯数1 + 歯数2）÷ 2 |
| かさ歯車（直交する軸の歯車） | `qm.bevel_gear` | 2 枚の pitch_angle の和を 90 に（小さい方は atan(歯数1/歯数2)）。それぞれの外側の端を、相手の基準円の半径だけ軸の交点から離して置く |
| 軸受 | `qm.ball_bearing` | 軸の直径を内径に。ハウジングの穴を外径に |
| フランジ・管の継ぎ目 | `qm.flange` ＋ `qm.ring` / `qm.tube` | ボルトは自動で円周に並ぶ |
| 車輪 | `qm.wheel(rotate=(90,0,0))` | 車なら軸を Y に。地面に接するよう中心の高さ = 半径 |
| ばね・コイル | `qm.helix` ＋ `qm.tube` | 線の太さは半径の 1〜2 割 |
| 同じ部品を並べる | `qm.array` / `qm.radial` / `qm.mirror` | 柵の柱・スポーク・ボルト円・左右の脚 |
| 翼・羽根・プロペラ | `qm.airfoil` ＋ `qm.loft`（F1 なら `f1.wing_element`） | 断面は NACA。下向きの力が欲しいなら camber を負に |
| F1・フォーミュラカー | `f1.car()` か `f1` の部品の関数 | 先に `f1_help` を読む。寸法は `f1.SPEC` / `f1.EST`、前は -Y |
| エンジン・コクピット・冷却（F1） | `f1.v6_engine` / `f1.intake` / `f1.exhaust` / `f1.turbocharger` / `f1.steering_wheel` / `f1.seat` / `f1.radiator` / `f1.pipe` | 位置は `f1.LAYOUT`（ミリ）にまとめてある。配管は通り道の点を、ほかの部品の外側に置く |
| サスペンション・ブレーキの機構 | `f1.wishbone` / `f1.pushrod` / `f1.rocker` / `f1.damper` / `f1.upright` / `f1.brake_disc` / `f1.caliper` | 先に取り付け点（ピボット・ボールジョイント）の座標を決め、部品はその点の間に作る。原点で作る部品は `qm.orient` で据える |

## 寸法の目安（メートル）

| 物 | 目安 |
|---|---|
| 椅子・スツール | 座面の高さ 0.42〜0.45、座面 0.35〜0.45 角、背もたれの上端 0.8〜0.9 |
| テーブル・机 | 高さ 0.70〜0.72、天板の厚み 0.025〜0.04、脚 0.04〜0.06 角 |
| 本棚 | 奥行 0.3、棚板の厚み 0.018〜0.025、棚の間隔 0.3〜0.35 |
| ドア・窓 | ドア 0.8〜0.9 × 2.0〜2.1、窓の腰の高さ 0.8〜1.1 |
| 建物 | 住宅の階高 2.8〜3.0、オフィス 3.5〜4.0、1 階の店舗 4.0〜4.5、手すり・パラペット 1.0〜1.1 |
| 宝箱 | 0.6〜1.0 × 0.4〜0.6 × 0.4〜0.5、帯の厚み 0.01〜0.015 |
| 小物 | マグカップ 直径 0.08 × 高さ 0.095、ワインボトル 直径 0.075 × 高さ 0.30、金貨 直径 0.025 |

## トポロジーのコツ

- 四角形の格子が形に沿うように分割を入れる。分割は均等に、細かすぎない（家具なら合計数千面で十分）。
- 部品どうしは無理に 1 つにつながない。別のオブジェクトとして重ねて置く（帯・金具・脚など）。
- 円柱や回転体の分割数（seg）は 4 の倍数にすると、フタの格子がきれいになる。
- サブディビジョンを使うなら、元の形は粗く、角の近くにだけ分割を足す。Bevel は `segments=2` 程度。

## よくある失敗

- **回転の軸の取り違え**：`qm.pivot` の point を、回したい辺の上に置く。高さ（Z）を入れ忘れると、ふたが浮いたり沈んだりする。
  浮いた場合は検査が「接していない部品」として返すが、めり込んだ場合は render でしか分からない。
- **matrix_world を直接いじる**：置いたばかりのオブジェクトの matrix_world は古いことがある。回すときは `qm.pivot` を使う。
- **向きの取り違え**：Z が上、正面は -Y 側（render の "front" は -Y 側から見た絵）。左右は X。
- **地面**：接地するものは底面を z=0 に。宙に浮かせる物（照明など）は `qm.expect(名前, floating=True)`。
- **テクスチャの向き**：UV は箱投影なので、木目は面の縦方向に流れる。曲面に模様をきれいに貼りたいときは、
  自分で UV を作り `mesh["keep_uv"] = True` を付ける。
- **bmesh の操作の引数**：Blender の版で変わることがある。エラーが出たら、qm の関数に置き換えられないか先に考える。

## マテリアル

- 部品ごとに `qm.material(名前, color=..., metal=..., rough=...)` を作って渡す。
- `list_textures` にある名前（Brick / Concrete / Wood / UVGrid など）のマテリアルには画像が貼られる。
  1 枚が何メートルかは `tile=`（木の板なら 0.5〜0.6、レンガ 1.0、コンクリート 2.0）。
- 金属は `metal=0.8〜1.0, rough=0.2〜0.5`、ガラスは暗い色に `rough=0.05, metal=0.5` 程度で見た目が出る。

## render の見方（毎回この順で確かめる）

1. 全体の比率：頼まれた物に見えるか。高さと幅の比が実物らしいか
2. 接し方：脚が床に、ふたが本体に、帯が面に、ちゃんと付いているか（めり込み・すき間）
3. 向き：正面が -Y 側を向いているか、上下が逆でないか
4. 辺の流れ：粘土色の絵で、格子が形に沿っているか、細かすぎる所・粗すぎる所がないか
5. テクスチャ：`look="material"` で、模様の大きさが実寸らしいか

## 実在する物を作るとき

1. 公表されている寸法を調べる（検索できるなら検索する）。記憶だけで数値を書かない
2. 裏付けが取れた値と、推定した値を分ける。スクリプトの先頭のコメントに、どちらかと出典を書く
3. 主な寸法は qm.expect で宣言する。推定値で作った部分は、ユーザーへの報告でも推定だと伝える

## ミリ単位で精密に作るとき（図面の下絵など）

1. スクリプトの先頭で `qm.units("mm")`。寸法は `MM = qm.MM` を使ってミリで書き、座標は `P(x, y, z)` のような関数でまとめる
2. 取り付け点（ピボット・ボールジョイント・ボルト穴の中心）の座標を先に表にし、部品はその点の間に作る
3. 左右対称なら、`for side in (-1, 1)` で X の符号だけを変えて両側を作る（ずれが出ない）
4. 確認は `render(views=["back", "left", "top"], ortho=True)`。グリッドと「1px が何ミリか」を見て、位置のずれを読む
5. 報告の X・Y・Z の範囲（ミリ）で、左右の部品が同じ値になっているか確かめる

## 図鑑のように描くとき

1. 部品のまとまり（例：クラッチ・デフ・ブレーキ）ごとに、オブジェクト名の先頭をそろえる（`Clutch_...`・`Diff_...`）
2. まとまりごとに `qm.catalog(key, title, description, parts=[先頭...], labels={先頭: 名前}, group=章)` を登録する
   - description は 1〜2 文で「何をする部品か」と主な寸法。裏付けのない数値は書かない
   - labels は 3〜8 個。多すぎると引き出し線が重なる。小さな部品（ボルト）より、役割のある部品に付ける
3. 図鑑のページは項目のオブジェクトだけを描くので、他の部品の中に隠れた物（ケースの中身）も見える
4. 名前の先頭が他の部品と重ならないか確かめる（`Brg_` が別のまとまりの軸受まで拾う、など）。報告に項目ごとの部品数が出る

## 作例

`examples/` に、検査を通った作例がある。似た物を作るときは読んでから書く。

- `treasure_chest.py`：qm だけで作った宝箱（box / loft / sweep / quad_sphere / pivot / expect）
- `stool.py`：回転体の座面と先細りの脚（lathe / tube / cylinder）
- `office_building.py`：bmesh で組んだ 8 階建てのビル（inset で窓、腰壁、パラペット、マテリアルの割り当て）
- `mechanical_parts.py`：ボルト・ナット・座金・歯車・フランジ・ばね・車輪（部品の関数の使い方）
- `f1_car.py`：f1.car で組み立てた 2026 年規定の F1 マシン（71 部品）
- `f1_front_corner.py`：モノコックと左前の足まわり（A アーム・プッシュロッド・ロッカー・ダンパー・ステアリング・アップライト・ブレーキ・ハブ・ホイール）
- `f1_rear_chassis_mm.py`：シャシーの後ろ（ギアボックス・ドライブシャフト・後輪の足まわり・ブレーキ）。寸法をすべてミリで書いた例
- `f1_gearbox_internals_mm.py`：ギアボックスの中身（クラッチ・入出力軸・前進 8 段・ドッグハブ・フォーク・シフトドラム・かさ歯車・デフ・軸受、半透明のケース）
- `f1_chassis_catalog_mm.py`：車体を除いたシャシーの全部品（サバイバルセル・コクピット・燃料・電池・V6 エンジンの外観と中身・吸排気・ターボ・MGU-K・冷却・前後の足まわり・ギアボックス）、細部（動弁系・点火・テザー・ブレーキ配管・油圧・電装）と、36 項目の図鑑（qm.catalog）
